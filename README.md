## Olá, sou Hiago Cardoso 😉

Sou **Arquiteto e Urbanista** 📐🖊, **Analista e Desenvolvedor de Sistemas** 💻 e **Especialista em Cidades Responsivas** 🗺️. Trabalho no setor público municipal, onde uso Python, geoprocessamento e automação para tornar mais ágil a análise de projetos e a aplicação da legislação urbanística. Tenho a Ciência de Dados aplicada ao urbanismo como foco de estudo e prática.

### Habilidades e Tecnologias 🎯

- **Linguagens**: Python, SQL
- **Frameworks e bibliotecas**: Flask, Django, PyQt, Tkinter, Pandas
- **Geoprocessamento**: QGIS, PyQGIS
- **Ferramentas**: Jupyter Notebook, n8n
- **Outros**: Análise de Dados Urbanos, Automação de Processos, Inteligência Artificial

### Projetos em Destaque 🚀

- [Análise de Dados de Emprego em Turismo](https://github.com/hiagoesc/analise-de-dados-novo-caged/): script em Python que analisa o emprego no setor de turismo com base nos dados do Novo CAGED.
- [Gerador de Coordenadas](https://github.com/hiagoesc/CoordinateGenerator): plugin em Python para QGIS que gera um arquivo com as coordenadas dos polígonos da camada ativa.
- [Gerador de Marcas d'Água](https://github.com/hiagoesc/watermark_app): aplicação em Python com interface Tkinter para inserir marcas d'água de texto em arquivos PDF.
- [Validador de Votos](https://github.com/hiagoesc/validador-de-votos): script em Python que valida os votos de um concurso gastronômico realizado online.

### Interesses 🔎

Tecnologia para o desenvolvimento das cidades, governo orientado por dados, geoprocessamento corporativo, automação de processos públicos, legislação urbanística, análise de dados de turismo e inteligência artificial.
